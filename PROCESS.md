# Process overview

## What I built

I brought back the nokia snake game to life. Although there may still be some 3310's chugging on, without the need for anything other than 2g radio signals and a measly 3.7V of electricity, I wanted to play the game again and so I built it. It only has one level, and the walls aren't permeable to make it more difficuly. The red dots appear randomly on a square grid and are persistent instead of timed to make it easier. 

## The moments that mattered

The moment that mattered was building the acceptance criteria. Keeping the initial prompts open-ended to allow the agent to have more creative free-reign and not box it into my view of the idea, it became a challenge to know when to stop. Althogh the complete appp did not take more than 3 sessions of on average 3 prompts, the criteria changed with every visible change on the local server running the game. Looking at something I had played so much as a child that it had practically become a screen-burn, it was hard to guide the agent to perfection. Hence, I took the symbolic path and made the re-design emphasise the simplicity of the nokia original game. Manually testing the game, the acceptance criteria became - Can I get lost in this game and lose track of time. Post my first few iterations, the only obstacle to this was the jittery motion of the snake. Got this corrected with a simple prompt and I had an experience where my mind went on autopilot and just focused on the game.
